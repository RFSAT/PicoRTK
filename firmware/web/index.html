PicoRTK · RTK GNSS rover

PicoRTK turns a Raspberry Pi Pico 2 W and a Quectel LG290P quad-band receiver (L1, L2, L5, E6) into a centimetre-level RTK rover. The Pico fetches RTCM corrections over Wi-Fi from up to four NTRIP sources in priority order: your own base, a VRS, the nearest network station, then a public caster. It switches to the next source automatically when one fails. Every correction frame is checked before it reaches the receiver. Without internet, the receiver can fall back to Galileo HAS (about 20 cm).

Failover

Sources are tried in order. A failure (no connection, no reply, rejected login or mount point, no RTCM for the timeout, or a correction age above the limit) moves to the next source. After every source has failed in a row the device waits (back-off) before starting again from source 1.

0 turns off "Return to source 1" and "Max correction age". The bench position is sent to VRS and nearest-station casters while the receiver has no fix, so they start streaming; leave latitude and longitude at 0 to turn it off.
